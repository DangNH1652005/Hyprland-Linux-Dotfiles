# Hyprland Linux Dotfiles

My personal dotfiles for **NixOS** with a customized Hyprland desktop environment.

This repository contains my configuration files for a minimal, keyboard-driven, and productive Linux workflow.

## ✨ Components

| Component | Description |
|---|---|
| [Hyprland](https://hypr.land/) | Dynamic tiling Wayland compositor |
| [Kitty](https://sw.kovidgoyal.net/kitty/) | GPU-accelerated terminal emulator |
| [Waybar](https://github.com/Alexays/Waybar) | Customizable status bar |
| [Rofi](https://github.com/davatorium/rofi) | Application launcher and menu |
| [SwayNC](https://github.com/ErikReider/SwayNotificationCenter) | Notification center for Wayland |
| [Wlogout](https://github.com/ArtsyMacaw/wlogout) | Logout and power menu |
| [Fastfetch](https://github.com/fastfetch-cli/fastfetch) | System information tool |

## 🖥️ Desktop Environment

- **Operating System:** NixOS
- **Window Manager:** Hyprland
- **Display Protocol:** Wayland
- **Terminal:** Kitty
- **Status Bar:** Waybar
- **Application Launcher:** Rofi
- **Notifications:** SwayNC
- **Power Menu:** Wlogout
- **System Information:** Fastfetch

## 🚀 Usage

Clone this repository:

```bash
git clone git@github.com:DangNH1652005/Hyprland-Linux-Dotfiles.git
cd Hyprland-Linux-Dotfiles
```

Review the configuration files and copy or link the configurations you need to the appropriate locations in your home directory.

**Note:** These dotfiles are designed for my personal setup on NixOS with Hyprland. You may need to adjust paths, packages, and settings to match your own system.
